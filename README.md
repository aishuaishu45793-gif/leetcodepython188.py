# Python Practice Projects 🐍

## About the Project
This repository contains five beginner-friendly Python programs designed to improve programming and problem-solving skills. Each program focuses on basic Python concepts such as loops, conditions, lists, strings, and mathematical operations.

## Projects Included

### 1. Armstrong Number Checker
Checks whether a given number is an Armstrong number.

**Example:**
- Input: `153`
- Output: `Armstrong Number`

### 2. Smallest Number in a List
Finds the smallest number from a list of user-provided numbers.

**Example:**
- Input: `25 10 45 5 30`
- Output: `Smallest Number: 5`

### 3. Remove Duplicates from a List
Removes repeated elements from a list while maintaining their original order.

**Example:**
- Input: `10 20 10 30 20 40`
- Output: `[10, 20, 30, 40]`

### 4. Factorial Calculator
Calculates the factorial of a given non-negative number.

**Example:**
- Input: `5`
- Output: `Factorial: 120`

### 5. Perfect Number Checker
Checks whether a number is equal to the sum of its proper divisors.

**Example:**
- Input: `28`
- Output: `Perfect Number`
